# Pendulums: Simulating a lot of Pendulums

Numerical simulation of a double pendulum in Python using a 4th-order Runge-Kutta integrator.


## Method
- Equations of motion derived using Lagrangian mechanics


## Getting Started
```bash
git clone https://github.com/your-username/Pendulums.git
pip install -r requirements.txt
```


## Built With
Python, NumPy, SciPy, Matplotlib
